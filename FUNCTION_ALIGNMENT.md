# TechPulse function alignment

This checklist records the comparison against `TechPulse-Guidance-Team-Axalan.pdf`.

## Kept and aligned

- Equipment registration, categorization, IDs, QR labels, locations, condition, and status.
- Borrow requests, approvals, releases, returns, overdue tracking, and borrowing history.
- Issue reporting, maintenance records, preventive maintenance schedules, and status history.
- Dashboards, equipment analytics, activity reports, audit logs, and role-based access.
- Admin tunnel/public-route controls, PC monitoring, gateway/network discovery, PC analytics, and mobile pairing/monitoring.
- Mobile equipment QR lookup, equipment borrowing requests, issue reporting, profile access, updates, and PC visibility.

## Removed from the applications

- Mobile PC-station booking and café session booking.
- Mobile wallet/balance top-up.
- Mobile café assistant/chat endpoint.

These removed items were application features unrelated to the equipment lifecycle scope. The retained PC, gateway, tunnel, analytics, and mobile connectivity functions remain available in the admin and mobile flows.
